# AGENTS.md


## Position (mandatory)

when adjusting the components all components must use absolute position and not relative so that when adjusting one component it wont disturb other components while adjusting the size and position of that certain component

## Versioning and Pushing (mandatory)

after completing a small, minor, or major update of the code:
1. commit the changes with a clear message that names the type of update (small/minor/major) and what changed
2. push the code to the remote repository
